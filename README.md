# רוח בדרך

אפליקציית אינטרנט בעברית המותאמת לאנדרואיד, עם תחזית רוח לאורך מסלול רכיבה באזור ישראל.

התהליך מתקדם שאלה אחת בכל פעם: מוצא → יעד → השוואת חלופות → תצוגת רכיבה. אחרי בחירת היעד מוצעות עד שלוש דרכים, עם אומדן זמן ורוח לכל דרך. בחירת דרך פותחת מפה, המחשת אופנוע וחצי רוח, ומחוון או סיור מונפש לאורך הנקודות.

שעת היציאה, הכבישים המועדפים ונקודות המעבר נפתחים רק לפי הצורך. החישוב מסרב להציג תחזית כאשר חסר כביש מבוקש. המפה הגאוגרפית דו־ממדית; ההמחשה של הרוכב מוצגת בפרספקטיבה.

בדיקת פקקים נפתחת בלחיצה ב־Google Maps או ב־Waze, לפי בחירת המשתמש להימנע מחיבור בתשלום. זמני הנסיעה בתוך האפליקציה אינם כוללים תנועה חיה. שירות הניווט עשוי לחשב דרך אחרת; התחזית כאן שייכת לדרך המוצגת כאן.

מוצגים רוח, משבים ורכיב רוח הצד עד 50 נקודות לפי שעת ההגעה. השעות מוצגות לפי Asia/Jerusalem; זמני נסיעה מבוססים על פרופיל רכב ללא תנועה בזמן אמת ועצירות. התחזית אינה קובעת שהרכיבה בטוחה.

## בטלפון

פתח את כתובת האפליקציה ב־Chrome באנדרואיד. בתפריט ⋮ בחר ״הוספה למסך הבית״ / ״התקנת אפליקציה״. נדרש חיבור לאינטרנט לחישוב. המקורות הציבוריים משמשים כאן לשימוש אישי לא מסחרי; לקראת הפצה מסחרית נדרש להסדיר ספקים, מגבלות שימוש ותפעול.

## פיתוח

הקבצים להפעלה נמצאים ב־dist. אין צורך בהתקנת תלויות או בבנייה.

```text
node scripts/serve.mjs
node --test tests/core.test.mjs tests/view.test.mjs tests/navigation.test.mjs
```

התחזית מתקבלת מ־[Open-Meteo](https://open-meteo.com/en/docs), חיפוש יישובים מ־[Open-Meteo Geocoding / GeoNames](https://open-meteo.com/en/docs/geocoding-api), מסלולים מ־[FOSSGIS / OSRM](https://routing.openstreetmap.de/about.html), ומפות מ־[OpenStreetMap](https://www.openstreetmap.org/copyright). הספרייה Leaflet כלולה עם הרישיון שלה. אין מפתחות API או סודות בקוד.

הנתונים הם תחזית מודל בגובה 10 מ׳, לא מדידה בכביש. מהירות וכיוון רוח עוברים אינטרפולציה וקטורית; המשב הוא המרבי משתי השעות הסמוכות. משב צד מחושב בכל שעה בהנחת כיוון הרוח השעתית, ונלקח המרבי. צבעי 20/35 קמ״ש הם טווחי תצוגה בלבד. אין מודל למנהרות, גשרים, חשיפה, צל רוח או תנועת משאיות.

מסלול שמור נשמר מקומית בדפדפן בלבד. תחזיות ומסלולים מהשירותים אינם נשמרים במטמון לשימוש ללא אינטרנט. נתוני המיקום והמסלול נשלחים לספקים לצורך החישוב.

המשך פיתוח: קרא את [מסמך המסירה לקלוד קוד](CLAUDE_HANDOFF.md).
